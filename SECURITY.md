# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/yanfishel/memoru/security/advisories/new),
not in a public issue. You will get an answer within a week.

Only the code in the latest release, which is what runs on [memoru.net](https://memoru.net), is supported.

## Not in scope

Mistakes in a person's record come from the source database. Report them on that person's page in the
[Open List](https://ru.openlist.wiki); the site picks up corrections with its monthly refresh.
